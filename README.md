#  Password Manager

## Features

- Master Password Login (SHA-256)
- Automatic SQLite Database Creation
- Add Password
- View Passwords
- Search Password
- Update Password
- Delete Password
- Password Generator
- Password Strength Indicator
- Show / Hide Password
- Copy Password to Clipboard
- Responsive Tkinter GUI
- Error Handling
- Object-Oriented Programming

---

## Technologies Used

- Python 3.14
- Tkinter
- SQLite3
